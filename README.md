# 刷流追新

适用于 MoviePilot v2 的多站点 RSS 刷流与追新插件。所有站点共用一个 MoviePilot 中已配置的 qBittorrent 下载器，连接信息只维护一次。

## 功能

- 首页切换站点，查看 qBittorrent 实时任务、处理记录并原位编辑规则。
- 每站点任意数量 RSS 任务：任务名可自定义，并配置必须关键词、排除关键词、分辨率、发种时间范围、文件大小范围和免费促销。
- 规则未选择分辨率时，可全局启用“同一影视仅下载最高分辨率”。同批 RSS 只选最高版本，跨轮次用 MoviePilot 插件数据持久化已知最高画质。
- 跟踪 RSS 可识别的免费截止时间，到期仍未完成时删除任务及未完成文件。
- 每站点任意数量删种规则，按照界面顺序匹配适用任务标签、满足做种小时数和满足分享率；一条任务只执行首条满足条件的规则。
- RSS 刷新、免费期检查、自动删种间隔分别配置，所有后台入口均包含互斥、防重入、异常日志和运行结果记录。
- qBittorrent 标签只使用 RSS 任务名；每个 RSS 条目的最终筛选结果、名称和下载链接都会写入 MoviePilot 日志。

## 安装

将本仓库地址添加到 MoviePilot v2 的第三方插件市场，或将 `plugins.v2/brushflowtracker` 安装为 v2 插件。插件源码已经包含 `dist/assets/remoteEntry.js` 前端构建产物。

安装后先在 MoviePilot 的“下载器”设置中配置并启用一个 qBittorrent，再进入“刷流追新”的全局设置选择它。插件不会重复保存 qBittorrent 地址、用户名或密码。

## 配置语义

### RSS 选种

- “必须包含关键词”采用全部包含；“排除关键词”命中任意一个即排除，匹配标题与描述且忽略大小写。
- 分辨率支持 8K、4K/2160p、1080p、1080i、720p、576p、480p。
- “发种时间范围”单位为分钟，例如 `0–30` 表示只选择发布不超过 30 分钟的条目。配置范围但 RSS 没有可解析发布时间时会排除。
- “文件大小范围”单位为 GiB，例如 `0–30` 表示只选择不超过 30 GiB 的条目。配置范围但 RSS 没有可解析大小时会排除。
- 免费促销可选不限、仅免费、免费或双倍上传免费、仅双倍上传免费。
- 任务名称必填且不能包含英文逗号。添加到 qBittorrent 时只使用任务名称这一个标签。

### 最高画质去重

启用全局去重后，所有站点和 RSS 任务的候选会先汇总，再按影视身份键只保留最高分辨率的一个；同一分辨率已有任务或下载链接已处理时不会再次加入。影视身份键会保留年份、季和集编号，并移除分辨率、来源、编码、HDR 等版本信息。新发现的画质必须高于持久化记录才会再次下载；插件不会自动删除此前已经下载完成的低画质文件。

### 免费期

插件优先读取 `freedate`、`free_until`、`free_end`、`promotion_end`，也支持从标题或描述解析“免费截止/Free until”和“免费剩余/Free remaining”。对 Audiences/NexusPHP 等 RSS 不返回促销字段的站点，会使用 MoviePilot 已保存的站点 Cookie 读取详情页中的“免费”徽章和剩余时间（例如“剩余时间：23时53分”）。如果 RSS 与详情页都没有截止时间，种子仍会按规则添加，日志会明确提示无法纳入到期自动删除。

### 自动删种

- 仅处理插件持久化记录中属于当前站点的 torrent hash，不会删除其他下载。
- 新增删种规则时会自动填入当前站点的全部任务名称；选择多个任务标签时命中任意一个即可。
- 做种时间和分享率同时达到阈值才匹配。
- 多条规则从上到下检查，命中第一条后停止。可分别选择是否同时删除文件。

## 数据与日志

去重记录、已处理 RSS 地址、托管任务、站点统计和历史均通过 MoviePilot 插件数据持久化。网络失败、qBittorrent 失败、RSS 过期、无法识别免费截止时间和删种结果都会写入 MoviePilot 日志。

RSS 刷新时，每个条目都会输出一条结构化日志，包含站点、任务、结果、原因、种子名称和下载链接。结果覆盖规则排除、同站点/跨站点低画质、历史去重、添加成功与 qBittorrent 添加失败。管理页的“处理记录”会展示已添加种子，点击名称可打开站点详情页。
